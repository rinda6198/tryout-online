# Tryout Online — Aplikasi Ujian Berbasis Website

## Tentang Proyek

Tryout Online merupakan proyek akhir perkuliahan berupa aplikasi ujian berbasis website yang dikembangkan untuk menerapkan pengetahuan dan keterampilan dalam pengembangan aplikasi web. Aplikasi ini dibangun menggunakan CodeIgniter 4 dan PHP dengan database MySQL.

Aplikasi menyediakan fitur pengelolaan pengguna, mata pelajaran, paket ujian, soal, pelaksanaan tryout, serta pengelolaan hasil ujian dengan pembagian akses berdasarkan peran Admin, Guru, dan Peserta.

## Tujuan Proyek

Proyek ini bertujuan untuk menerapkan konsep pengembangan aplikasi web, pengelolaan basis data, autentikasi pengguna, serta implementasi fitur ujian online dalam sebuah proyek perkuliahan.

## Fitur Utama

- **Admin:** Pengelolaan pengguna, mata pelajaran, dan pengumuman.
- **Guru:** Pengelolaan paket ujian dan soal serta pemantauan hasil ujian.
- **Peserta:** Pelaksanaan tryout online dan akses riwayat hasil ujian.
- **Hasil Ujian:** Penyajian hasil pengerjaan dan analisis nilai.

## Teknologi

- PHP
- CodeIgniter 4
- MySQL
- HTML, CSS, dan JavaScript
- Composer

## Menjalankan Proyek

1. Clone repositori GitHub.
2. Instal dependensi menggunakan `composer install`.
3. Konfigurasikan file `.env` dan database MySQL.
4. Jalankan migrasi database sesuai kebutuhan proyek.
5. Jalankan aplikasi dengan `php spark serve`.
